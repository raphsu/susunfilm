## 00｜先講三個會影響整個專案的發現

**一、這不是「重構」，是「從零建站」。**
工作目錄 `/Volumes/擴充SSD_1TB/Claude AI` 底下沒有任何蘇珊日常的網站專案。三個 `package.json`（STB、ALIGNED、chiao-rpg）都是別的東西。`git status` 不適用——這裡不是 git repo。所以第 34 條「不要破壞現有網站」實際上沒有需要保護的對象，我們是全新開專案。已建好 `susunfilm/docs/` 放這份 Audit，其他什麼都還沒動。

**二、圖片資產是 0。**
掃過 `/public`、`/src/assets`、`/assets`、`/images` 以及整個工作目錄：206 張圖片全部屬於別的專案（后土祭 AI 角色圖、STB／ALIGNED 軟體截圖、app icon）。唯一的橋頭照片藏在 `03 橋頭咧咧相.pdf` 裡，26 張內嵌圖，最大只有 1280×857，多數不到 900px——當縮圖都勉強，不可能當 hero。**一個以「影像是第一主角」為原則的網站，現在手上沒有任何一張可用的高解析照片。這是唯一真正的阻擋點。**

**三、蘇珊日常已經有自己的顏色了，不是黑白。**
IG 大頭貼是實體 LOGO：霧綠圓底 + 米白字。取樣後主色為 **`#678472`**（一種偏灰的尤加利／鼠尾草綠）。這跟蘇夫映像 Raphsufilm 的純黑白無彩色系統是**兩套**，正好呼應你在第 04 條說的「兩者不要混成同一個品牌」。第 24 條說「Accent 從實際攝影作品中取色」——不用取了，你的 LOGO 已經給了答案。

## 15｜新網站 Design Direction

**氣質**：Japanese Editorial × Local Zine × Documentary。安靜、慢、大量留白、非對稱。

**Color**（Accent 來自你自己的 LOGO，不是我發明的）

```
--ink          #1A1A1A   主文字
--ink-soft     #4A4A4A   次要文字
--paper        #F7F5F1   紙白底（暖，不是純白）
--paper-warm   #EDE9E2   區塊底
--rule         #D8D3CA   分隔線
--moss         #678472   ← 取自 LOGO 實際取樣，品牌綠
--moss-deep    #4C6355   hover / 深色
```

用法克制：`--moss` 只出現在連結 hover、當前導航、分類標籤、引言縱線。**不做大面積色塊。**照片本身就是顏色。

**Typography**

```
Display  Noto Serif TC        地方感的中文襯線，只給大標與引言
Body     Noto Sans TC         內文
Latin    Inter                年份、地點、分類、Credits 這類資訊層
```

節奏：Hero 標題 clamp(2.5rem, 6vw, 5rem)；內文 17–18px / line-height 1.9（中文要更鬆）；字距 letter-spacing .02em；每行控制在 32–38 中文字。

**Grid**

12 欄，max-width 1280（內文區收到 680）。刻意非對稱：文字區塊靠左 2–7 欄或靠右 6–11 欄交替，圖片允許 bleed 出欄外。**不全部置中。**

**Image**

不統一裁切比例，橫／直／方混排。Project Detail 用 Photo Essay 節奏：full-bleed 大圖 → 一段短文 → 雙圖並置（一橫一直）→ 人物特寫 → 影片 → 故事 → Credits。全部 lazy load + `aspect-ratio` 佔位避免 CLS。

**Motion**

只有三種：`fade-up`（16px、600ms、ease-out、進場一次）、圖片 `scale 1.0→1.03` 需 4s、頁面轉場 opacity 300ms。全部包在 `prefers-reduced-motion` 裡。**不做 mouse follow、不做 parallax、不做 WebGL。**

**技術**

React + TypeScript + Vite + Tailwind。路由 React Router。SEO 用 react-helmet-async（或改用 Astro——若你希望 SSG + 更好的 SEO，Astro 其實更適合這種內容型網站，但 React 是你第 29 條指定的，我照做）。

**資料層**（第 31 條）

```

├─ site.ts            站台 meta、導航、社群連結、SEO 預設
├─ about.ts           自我介紹、Timeline

├─ projects/          一支專案一個檔，符合你第 30 條的 Project schema
│   ├─ index.ts
│   └─ qiaotou-leleXiang.ts …
```

每個檔案加一個 `status: 'verified' | 'review' | 'draft'` 欄位——`review` 和 `draft` 不進 build，這樣你的「不要把 NEED REVIEW 當 VERIFIED」就變成程式強制的規則，不是靠人記得。

## 需要你確認的 8 個問題

1. **圖片什麼時候給？** 這是唯一的硬阻擋。至少要 5 張 2400px+ 的橋頭原檔，加 LOGO 的 SVG 或大尺寸 PNG。沒有這批檔案，網站可以蓋起來但只能是空殼。

2. **主專案叫什麼？** 現在有五個名字在跑：橋仔頭日常影像誌／橋仔頭，好好生活／橋頭晨昏散策記錄／《家》的生活筆記／橋仔頭晨昏日常：家的散步故事。請定一個，其餘我標成「曾用名」。

3. **核心句要用新的還是舊的？**「把日常留下來，地方就有了自己的樣子」是這次新給的，三個來源都沒有。你自己反覆用過的是「家的模樣，不在模板裡，而在每一次轉角招呼、每一段靜靜留下的日常之中」。依第 08 條，我傾向後者；但第 38 條你指定了前者。**兩者衝突，請裁示。**（也可以：前者當 Hero，後者當 STORY 開場。）

4. **W∞D學、台糖社會住宅｜造夢者、前鎮漁港｜鱻滿藝築的海籽——三個來源全都沒有。** 要標 `[待補資料]` 先留空位，還是這一版先不放？

5. **咧咧相 2026 秋季五場是定案嗎？** 本機那份 `index.html` 寫得很完整但報名網址是空的。定案我就整套搬進 COLLABORATION；沒定案我先放「2026 秋季場次規劃中」。

6. **委製案要不要進站？** 美濃、大寮、衛武營、雙流、成大這些是 RaphSuFilm 的客戶委託。我的建議是進 COLLABORATION（「一起做過的事」），不進 PROJECTS（自主創作）——這樣兩個品牌的界線才守得住。你同意嗎？

7. **蘇珊本人要不要出現？** 品牌叫「蘇珊日常」，但三個來源裡所有第一人稱文字都是小夫寫的，蘇珊沒有留下任何一句自述。ABOUT 頁要寫成「我」（一個人）還是「我們」（兩個人）？如果是「我們」，需要蘇珊的一段自介。

8. **Instagram 就用手動，可以嗎？** IG Basic Display API 已停用，Graph API 要 FB 商業帳號審核 + Token 每 60 天輪替。以 155 粉絲的規模不值得。我建議做本地 `content/instagram.ts` 手動放 6–9 張，配外連。
